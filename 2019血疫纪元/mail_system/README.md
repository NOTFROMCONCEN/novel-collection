# 📧 邮箱系统模板

这是一个用于小说世界观展示的虚拟邮箱系统模板。

## 项目说明

这是一个纯静态的邮箱界面模板，用于辅助小说创作和世界观构建。所有邮件内容都是预设的示例数据，不涉及真实的邮件收发功能。

## 功能特性

- ✉️ 邮件列表显示
- 📖 邮件详情查看
- 🔴 未读/已读状态管理
- 📱 响应式设计（支持桌面和移动设备）
- 🎨 现代简约风格界面

## 文件结构

```
mail_system/
├── index.html          # 主页面
├── css/
│   └── style.css      # 样式文件
├── js/
│   └── mail.js        # 交互逻辑
└── README.md          # 项目说明（本文件）
```

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 点击左侧邮件列表查看邮件详情
3. 邮件会自动标记为已读状态

## 示例邮件

系统预设了5封示例邮件：
1. 工作周报
2. 项目会议通知
3. 朋友问候
4. 新项目任务分配
5. 年会活动邀请

## 自定义修改

您可以在 `js/mail.js` 文件中修改 `mailData` 数组来添加或修改邮件内容，包括：
- 发件人姓名和邮箱
- 收件人信息
- 邮件主题
- 邮件正文
- 发送时间

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript

## 注意事项

- 这是一个静态演示模板，所有数据都是前端预设的
- 不包含任何后端服务或真实的邮件功能
- 适合用于小说场景展示、世界观构建等创作辅助用途
