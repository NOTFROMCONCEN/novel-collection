## 📖 小说项目详情

### 夏夜

**类型**：黑暗现实 / 心理剧 / 悲剧  
**状态**：进行中  
**总字数**：约14万字

包含三个子故事系列：

#### 《囚鸟与画师》（主要故事）

画师江屿与富家女许薇之间由爱生恨的扭曲关系。许薇曾伤害江屿导致其犯下大错，多年后许薇以复仇姿态回归，将江屿囚禁令其画画赢回荣誉。两人在恨意、艺术与肉体精神的纠缠中互相折磨。

**核心主题**：复仇、禁锢、艺术、救赎，以及在极致的恨意与痛苦中扭曲共生的病态关系。

**章节结构**：
- 序章~第六章：契约与牢笼
- 第七章~第十章：面具与獠牙
- 第十一章~第十二章：审判与终局

#### 《夏夜》

美术生林夏夜被闺蜜陈婧背叛，人生崩塌后堕入黑暗世界。最了解你的人，才知道如何用最精准的方式，让你万劫不复。

**核心主题**：背叛与信任、创伤与堕落、控制与被控制、嫉妒与毁灭

**章节结构**：
- 第一章~第二章：铺垫与伪装
- 第三章：精准打击
- 第四章~第五章：万劫不复
- 第六章~第十章：深渊中的交易
- 第十一章~第十四章：回声

#### 《最难忘的夏天》

一个关于短暂夏日之恋的悲剧。男主角遇到从城市转学来的女主角，两人坠入爱河。夏天结束时她不告而别，多年后男主角才得知她身患绝症，那个夏天是她生命最后的"缓刑"。

**核心主题**：记忆与遗忘、爱与失去、生命的脆弱与永恒

### 2019血疫纪元

**类型**：科幻 / 生物恐怖 / 末日生存  
**状态**：已完成（四部曲）  
**体量**：约30万字+

#### 故事梗概

2019年12月，跨国生物科技巨头"永生树集团"在中国X市秘密启动"盖亚之巢"项目，实验失控导致硅基-碳基混合智慧体"母亲"突破控制，蓝色菌丝通过通风系统扩散全城。感染47,000余人，死亡15,000人以上。政府秘密机构"第7工作组"执行净化协议。两年后，全球17个城市同时检测到异常信号，盖亚的菌丝网络在地球上已存在超过50年。最终幸存者K-8成为人类与盖亚之间的"翻译"，促成共存。

**核心主题**："什么是人类"——进化vs守旧、集体vs个体、恐惧vs理解、科技伦理

#### 四部曲结构

| 部分 | 标题 | 时间线 |
|------|------|--------|
| 起源篇 | 前传（3章） | 2019年8-12月 |
| Part 2 | 入城记 | 2019年11-12月 |
| Part 3 | 净域残响 | 2020年12月—2021年春 |
| Part 4 | 根系蔓延 | 2023年3月—10月 |

### 小黑屋

**类型**：心理恐怖 / 身体恐怖 / 克苏鲁式畸变文学  
**状态**：进行中  
**体量**：5个Markdown文件

#### 故事概览

包含三个独立故事：

1. **《雕塑》三部曲**：一个只雕刻冰冷石头的精确型雕塑家，偶然获得一块红色陶土后被原始的创作冲动吞噬。他疯狂创作出令人作呕的泥塑，泥塑不断"长大"，雕塑家最终准备与之合为一体，被送入疗养院。

2. **《认知坍缩》**：叙述者认知完全崩塌，将世界万物全部解读为"材料"和"素材"，不再将人视为人，而是"未成形的泥"。

3. **《自我校准》**：叙述者被某种装置"校准"后，身体内部产生了刻入骨髓的条件反射，发现自己的手在无意识中以"非人的精准"探索自己的身体。

**核心主题**：创作欲与毁灭欲的一体两面、控制与失控、身体的异化与背叛、认知的脆弱性

### 浮楼劫烬

**类型**：暗黑现实主义 / 虐心文学  
**状态**：进行中  
**体量**：正篇3章+番外4章

#### 故事梗概

富商陆沉耗资数亿建造豪华建筑"朱楼"作为与爱人林晚的爱巢，但他的爱是窒息性的控制。林晚从朱楼露台坠亡后，陆沉找到容貌酷似林晚的底层青年子衿，将其囚禁为替身。子衿在替身生活中发现林晚藏在书页中的秘密，自我意识开始萌芽。朱楼倒塌后，子衿自取名"江离"重生，在废墟中与沦为流浪汉的陆沉重逢，两个破碎灵魂在废墟中展开危险的碰撞。

**核心主题**：控制与自由、身份认同与自我觉醒、幻象与真实、权力的腐蚀与崩塌

### 溟濛

**类型**：科幻悬疑 / 克苏鲁风格 / 末日生存 / 都市奇幻  
**状态**：进行中  
**体量**：20个文件

#### 故事梗概

2033年，全球疫情已持续13年。2022年南极科考队发现"异能辐射"，创造了第一批异能者。随后出现多种灾难性事件：AI失控的"算法巴别塔"、脑机接口士兵集体幻觉的"量子谵妄"、疫苗引发时空畸变的"克莱因疫苗灾难"。核心威胁是"认知瘟疫"——一种能够扭曲现实、改变认知的现象。故事围绕咖啡店主话梅糖和普通市民祈空展开。

**核心主题**：存在与自我、记忆与认知、科技与伦理、古代与未来的对话

## 🎨 写作风格共性

| 维度 | 特点 |
|------|------|
| **题材偏好** | 黑暗、心理、科幻、末日——探索人性的极端状态 |
| **叙事手法** | 多视角、碎片化叙事、多体裁交织（档案、日记、新闻、广播） |
| **文风特点** | 文学性强，感官描写细腻，氛围营造突出，从日常平缓滑入恐怖 |
| **角色塑造** | 内心复杂，常处于控制与被控制、记忆与遗忘的张力中 |
| **意象运用** | 建筑空间（朱楼、防空洞）、身体异化、颜色/气味等象征 |
